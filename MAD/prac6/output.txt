2. Select "Empty Views Activity" template.
3. Configure project:

   - Package Name: com.example.prac_6
   - Language: Java

4. Click "Finish".

5. UPDATE MANIFEST FILE (CRITICAL):

6. UPDATE / CREATE LAYOUT XML FILES:

     (Replace with 'activity_main.xml')
   - File 2: In 'res/layout', Right-click -> New -> Layout Resource File.
     Name: home_page.xml
     (Replace with 'home_page.xml')

7. UPDATE / CREATE JAVA FILES:
   - File 1: app -> src -> main -> java -> com.example.prac_6 -> MainActivity.java
     (Replace with 'MainActivity.java')
   - File 2: In 'com.example.prac_6' package, Right-click -> New -> Java Class.
     Name: PageHome
     (Replace with 'PageHome.java')
